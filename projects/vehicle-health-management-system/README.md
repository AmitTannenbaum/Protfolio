# Vehicle Health Management System

## Overview
A comprehensive data analysis project focused on vehicle health management system improvement. This project demonstrates skills in data cleaning, statistical analysis, and data visualization.

## Files
- `Vehicle_health_management_system_.ipynb` - Jupyter notebook containing the full analysis
- `Vehicle Health Management System Improvement-PRD.docx` - Product Requirements Document

## Technologies Used
- Python
- Jupyter Notebook
- Data Analysis Libraries (Pandas, NumPy)
- Data Visualization (Matplotlib, Seaborn, Tableau)

## Tableau Dashboard
The interactive dashboard can be viewed here:
[Vehicle Health Management System Dashboard](https://public.tableau.com/views/product_owner_dataanalyst_home_assignment/VehicleHealthManagementSystem)

## Key Insights
This project analyzes vehicle health data to provide actionable insights for system improvements.

## How to Run
1. Install required dependencies: `pip install jupyter pandas numpy matplotlib seaborn`
2. Open the Jupyter notebook: `jupyter notebook Vehicle_health_management_system_.ipynb`
3. Run all cells to see the analysis
